# Pet Takamatsu Lantern Penguin

A Minecraft Fabric mod that adds a cute penguin pet based on **Takamatsu Lantern** (高松灯) from *BanG Dream!*.

## Features

- 🐧 **Penguin Pet** — a shoulder-riding penguin companion with idle/happy/excited/hurt animations
- 🎯 **Block Slingshot** — a throwable block item with special pulling animations
- 🎭 **Expression Wheel** — interact with your pet to show expressions
- 🔊 **Custom Sounds** — pet voice lines and boss theme
