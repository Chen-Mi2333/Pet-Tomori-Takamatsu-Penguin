# Pet 高松灯企鹅（Pet Tomori Takamatsu Penguin）

一个 Minecraft Fabric 模组，添加了一只以《BanG Dream!》中的**高松灯**为原型的可爱企鹅宠物。

[English](README.md) | 中文

## 功能特性

- 🐧 **企鹅宠物** — 可以站在肩膀上的企鹅伙伴，具备待机/开心/兴奋/受伤等多种动画
- 🎯 **方块弹弓** — 可投掷的方块物品，带有独特的拉弓动画
- 🎭 **表情轮盘** — 与宠物互动即可展示各种表情
- 🔊 **自定义音效** — 宠物语音和 Boss 战主题曲
